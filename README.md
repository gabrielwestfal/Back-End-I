# Back-End I

Repositório desenvolvido para a disciplina de **Back-End I**, do 2º período do curso de **Tecnologia em Sistemas para Internet (TSI)** do **IFES – Campus Santa Teresa**.

O objetivo deste repositório é reunir as atividades, exercícios e projetos desenvolvidos ao longo da disciplina, registrando a evolução dos conhecimentos relacionados ao desenvolvimento back-end e à criação de aplicações web.

## Sobre a disciplina

Durante a disciplina são trabalhados conceitos fundamentais de desenvolvimento back-end, programação e construção de aplicações web, colocando em prática os conteúdos apresentados em aula por meio de atividades e projetos.

## Conteúdos e atividades

Atualmente, o repositório está organizado nas seguintes atividades:

### Funções de texto

Pasta destinada às atividades relacionadas à criação e utilização de funções para manipulação de textos.

### Gerando funções

Atividades voltadas para a criação de funções e transformação de códigos, colocando em prática conceitos de programação e organização do código.

### Projeto de postagens

Projeto desenvolvido para aplicar os conhecimentos estudados durante a disciplina, trabalhando com uma aplicação relacionada ao gerenciamento de postagens.

## Objetivos

* Aprender conceitos fundamentais de desenvolvimento back-end;
* Praticar programação utilizando PHP;
* Desenvolver e organizar funções;
* Trabalhar com páginas e aplicações web;
* Aplicar conceitos de programação em projetos práticos;
* Utilizar Git e GitHub para versionamento e organização dos projetos.
